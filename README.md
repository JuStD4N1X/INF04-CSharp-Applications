# C# OOP & Algorithmic Applications (INF.04)

A collection of C# console and desktop applications developed based on the INF.04 vocational examination tasks.

## Key Features & Technologies
- **Language:** C# (.NET)
- **Core Concepts:** Object-Oriented Programming (OOP), Data Encapsulation, Input Validation
- **Algorithms:** Data processing, checksum/ID validation logic (e.g., PESEL verification), and array sorting
- **Architecture:** Clean code structure following standard C# naming conventions

# C# WPF Desktop Applications (INF.04)

A collection of C# WPF (Windows Presentation Foundation) desktop applications featuring graphical user interfaces (GUI), built according to official INF.04 vocational examination practical tasks.

## Key Features & Technologies

* **Language & UI:** C# (.NET) & WPF (Windows Presentation Foundation)
* **Interface Design:** XAML layout structure, control bindings, and event-driven architecture
* **Core Concepts:** Form handling, input validation, dynamic image/text switching, and business logic
* **Code Standard:** Clean object-oriented structure adhering to `PascalCase` C# conventions

## How to Run

1. Clone the repository: `git clone [https://github.com/JuStD4N1X/INF04-CSharp-Applications.git](https://github.com/JuStD4N1X/INF04-CSharp-Applications.git)`
2. Open the desired project folder or `.sln` file in **Visual Studio**.
3. Press **F5** to compile and run the application.
